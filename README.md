# ATM System Web API

Бэкенд-сервис для управления банковскими счетами и сессиями (создание счетов, пополнение, снятие средств, аудит истории операций).

## Архитектура и технологии

* **Hexagonal Architecture (Ports & Adapters):** Полная изоляция бизнес-логики (домена) от инфраструктуры хранения данных и Web-представления.
* **ASP.NET Core Web API:** Реализация слоя представления через контроллеры, роутинг и обработка HTTP-статусов (`400 BadRequest`, `401 Unauthorized`).
* **Dependency Injection:** Модульная регистрация сервисов и репозиториев через `Microsoft.Extensions.DependencyInjection`.
* **Unit Testing:** Покрытие доменной логики модульными тестами (`xUnit`) с использованием моков (`NSubstitute`) без привязки к базе данных.
